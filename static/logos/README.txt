Company logos for FINN
======================

Drop logo files here named by NSE symbol, for example:

    POLYCAB.png
    TCS.svg
    HDFCBANK.webp

Accepted formats: .svg, .png, .webp. Square images work best (FINN shows them at 24-28 px
on a light tile with object-fit: contain). The symbol part of the file name is case-insensitive.

Until a file exists for a symbol, FINN shows a monogram tile (the first two letters of the
symbol on a colour derived from the symbol), so any company, including ones added later or
researched without being held, always has a mark. No logo is ever fetched from the internet.

Only add logos you have the right to use. Company names and logos belong to their
respective owners and are used only to identify the companies.
